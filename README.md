
# Kaushalya Karnataka – Skilled Worker Booking Platform

## Overview
Kaushalya Karnataka is a mobile application designed to connect customers with skilled workers such as electricians, plumbers, carpenters, painters, and mechanics. The platform enables users to search workers, view profiles, book services, manage bookings, and track notifications.

The application also includes a dedicated worker dashboard for managing requests, earnings, profiles, and availability.

---

## Features

### Customer Features
- User Registration & Login
- Search Skilled Workers
- Filter Workers by Category
- View Worker Profiles
- Book Services
- Booking Management
- Notifications & Alerts
- Help & FAQ Section

### Worker Features
- Worker Registration
- Profile Management
- Booking Request Handling
- Earnings Dashboard
- Availability Toggle
- Notification Preferences
